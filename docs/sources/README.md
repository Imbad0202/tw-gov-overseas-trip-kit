## 主要法規

### 1. 國外出差旅費報支要點

- **版本**：114.05.13 修正、115.01.01 生效
- **文號**：院授主預字第1140101390號函
- **URL**：https://law.dgbas.gov.tw/LawContent.aspx?id=FL017584
- **說明**：計算機關出差旅費（交通費、住宿費、雜費、日支生活費）的核心規則，本工具計算邏輯以此為準。衝突時以此版本為最終依據。

### 2. 生活費日支數額表

- **版本**：114.10.31 修正、115.1.1 生效
- **文號**：院授主預字第1140103430號函
- **URL**：[主計總處日支表及沿革](https://law.dgbas.gov.tw/LawContentSource.aspx?id=FL028084)
- **說明**：各國每日生活費補助上限，**逐年更新**。本工具不內建表格數值；使用者帶入時應以出差日期適用版本為準，自負其責。

### 3. 國外出差旅費報支要點解釋彙編

- **版本**：107.4 修編（103.1 編訂）
- **URL**：[主計總處全文 PDF](https://www.dgbas.gov.tw/public/Data/0729174810BYSDYTB1.pdf)
- **說明**：對要點各條文的官方函釋與主計長信箱答復彙整，本工具計算邏輯設計時作為參考。逐案索引（含函釋文號、要旨、與現行條文差異）見 [docs/解釋彙編逐案索引.md](../解釋彙編逐案索引.md)。彙編自述「並非法規或制度之訂頒」，僅供參考，不覆蓋現行條文；彙編收錄至 107 年 4 月，之後函釋另查。

### 4. 行政院出國報告綜合處理要點

- **版本**：107.06.20
- **附件**：附件一（出國報告格式）、附件二（出國報告審核表）
- **URL**：[國發會主管法規系統](https://theme.ndc.gov.tw/lawout/LawContent.aspx?id=GL000288&media=print)
- **說明**：報告與審核表 DOCX 的格式依據；HTML 是行前手冊，Excel 是美元規劃表，並非附件二。
